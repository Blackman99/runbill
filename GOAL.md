# Goal

**Show, in one command, which GitHub Actions workflows and jobs your minutes and money go to, billed the way GitHub bills them.**

In scope: per-workflow / per-job / per-runner breakdown from the public API, GitHub's rounding and runner
multipliers, re-run cost, budget gates, CI-friendly output, org-wide rollups.

Out of scope: invoice reconciliation, CI optimisation advice engines, dashboards/servers, non-GitHub CI systems,
anything that needs more than read access to Actions.
