GitHub Actions minutes & cost, per workflow and per job

Who ran up the Actions bill?

GitHub shows you one total. runbill builds every workflow as a building and lays each job's billed minutes as bricks, priced by runner. A macOS minute is ten Linux minutes tall.

GitHub list prices per minute, every larger-runner size included; override any of them with --rate macos=0.08. A 40-second job lays a whole brick: GitHub bills each job in started minutes.

How the building is measured

  1. Site. List completed runs in the window from /actions/runs. Public and private repos, any plan.
  2. Every job. Pull all jobs of each run, earlier attempts included, so re-runs show up as their own cost.
  3. Material. Read each job's runner labels: Linux, Windows, macOS, arm, self-hosted, and size (N-cores, macOS large/xlarge, ubuntu-slim) at its published rate.
  4. Round up. Each job is billed in whole minutes. A 40-second lint job is a one-minute brick.
  5. Rooftop. Rank workflows and jobs by cost, show the re-run share, and optionally fail CI over a budget.

Break ground

CLI. Python 3.9+, no dependencies; uses GH_TOKEN or your gh login.

pipx install git+https://github.com/Blackman99/runbill
runbill OWNER/REPO --days 30

Action. Writes the report to the job summary.

- uses: Blackman99/runbill@v0.1.0
  with:
    days: 30
    fail-over: 50   # optional budget gate, USD
